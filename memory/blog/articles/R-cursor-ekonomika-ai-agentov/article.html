Игорь искал "бесплатные AI агенты", услышал, что "всем нужны агенты для бизнеса", купил дорогую связку "флагман + OpenClaw-класс + ещё чат" и запустил агента без фразы "что считать готовым". Агент час крутил одно и то же, счёт вырос, файла поста нет. Страх знакомый: агенты = куча подписок и счёт как зарплата. Ответ проще: один прогон в Cursor на Composer, критерий готовности и чеклист лимитов – без зоопарка вкладок "на всякий случай".

Когда не гоняться за "бесплатными агентами"

Если задача разовая и вы у экрана – обычный чат на Composer дешевле зоопарка подписок. Если нужен только перевод строки Sheets→Telegram – начните с Make, не с Max Mode. Типичная ошибка: купить "флагман на всякий" без критерия "готово" и сжечь бюджет на пустом цикле. На практике сначала один артефакт и стоп-кран, потом облако.

Для рутины берите Composer 2.5 / Auto в first-party пуле Cursor, а не Claude Opus "потому что круто". Официально Composer 2.5 стоит $0.50 / $2.50 за 1M input/output токенов, Opus 4.8 – $5 / $25. Перед запуском напишите одно предложение "артефакт готов, когда…". Make оставьте для линейных сценариев. Ориентир вечера: одна задача → Composer → usage dashboard → файл или явный стоп.

Выберите Composer, а не Opus "на всякий случай"

Боль "купил Opus/Claude/OpenClaw и боюсь смотреть счёт" закрывается выбором модели по умолчанию. Cursor Individual Pro – от $20/мес. Внутри два пула: first-party (Auto, Composer 2.5, Grok) с щедрым included-usage и API-пул для frontier (от ~$20 API на Pro). Frontier ест отдельный карман.

Например, независимый разбор по Coding Agent Index давал ~$0.07 за задачу на Composer 2.5 standard против ~$4.10 на Opus max. В @maya_pro (#1314) Composer называют примерно в 10 раз дешевле топовых для агентных задач. Новички часто платят как за Opus, хотя задача рутинная.

  1. Шаг 1. Откройте Cursor и выберите Composer 2.5 или Auto – не Opus.
  2. Шаг 2. Запишите задачу одной фразой и критерий "готово".
  3. Шаг 3. Проверьте usage dashboard до прогона.
  4. Шаг 4. Сделайте короткий прогон на одном артефакте.
  5. Шаг 5. Снова откройте usage – зафиксируйте расход.
  6. Шаг 6. Если Composer не справился – только тогда пробуйте frontier на той же задаче.

Избегайте Max Mode + Opus на первом эксперименте. Hobby годится потрогать Tab/Agent limits, но для бизнес-артефакта обычно нужен Individual. Не собирайте зоопарк "бесплатных ai агентов" из пяти вкладок – один рабочий инструмент сильнее.

Напишите критерий "готово" и поставьте стоп-кран

Боль "агент крутится без критерия и жжёт токены" – история Игоря. В GitHub OpenClaw: unhealthy session жгла ~3.86M input tokens при ~9.5K output в retry-storm; на 402 billing – тысячи failed runs без backoff. Circuit breaker в idle-timeout оценивали как "десятки долларов vs центы".

На пальцах агент – помощник, который сам ходит по шагам. Без фразы "готово, когда…" он ходит кругами. Добавьте в ТЗ одно предложение и лимит попыток.

  1. Шаг 1. Напишите: "Артефакт готов, когда есть файл X / черновик Y / правка Z".
  2. Шаг 2. Уберите из промпта "будь полезным маркетологом на всё".
  3. Шаг 3. Поставьте стоп после 2–3 неудачных циклов без нового ТЗ.
  4. Шаг 4. Не перезапускайте тот же промпт без правки входа.
  5. Шаг 5. Сохраните удачный промпт рядом с задачей.
  6. Шаг 6. Если задача линейная (форма→таблица→уведомление) – вернитесь в Make.
  7. Шаг 7. Проверьте: в конце есть файл или явный стоп, а не "час в никуда".

Типичная ошибка – считать "агент думает" результатом. Результат – артефакт. В реальном проекте цикл "один запуск = один артефакт" спокойнее хаотичного стека: например, rss-ai-telegram.

Как не сжечь бюджет на Cloud Agent и Max Mode

Боль "Cloud / Max Mode съел бюджет за один прогон" решается правилом: Cloud – когда нужен 24/7 или прогон без ноутбука, не для первого вечера. По docs Cursor Cloud Agents биллятся по API-цене модели, всегда в Max Mode, при старте просят spend limit, нужен paid plan.

Сделайте так: сначала локальный прогон на Composer. Потом Cloud + spend limit + дешёвая модель. Не делайте Ultra ($200/мес) и Cloud "сразу на всё". Docs намекают: daily Tab часто в $20, daily Agent – $60–100, power/automation – $200+.

Схема безопасного роста:
Локальный Composer → usage ок → spend limit → Cloud на той же задаче → только потом расписание 24/7

Если тянет в облако – гайд Cursor Cloud Agents. Для вайбкодинга маркетинга – вайбкодинг в Cursor.

Чеклист месяца: минимальный стек вместо зоопарка

Боль "бесплатные AI агенты = хаос без результата" закрывается дисциплиной на 30 дней. Около 40% проектов автономных агентов отменяют из-за скрытых затрат и нулевого ROI – чаще из-за отсутствия стоп-крана, а не "плохого ИИ".

  • Стоп после 2–3 провалов без нового ТЗ.

  • Cloud / Max – после локального успеха + spend limit.

Частые вопросы

С какого тарифа Cursor начать новичку, чтобы не слить бюджет?

Hobby – чтобы понять интерфейс; для Agent и реальной задачи обычно Individual Pro от $20. Сразу Composer/Auto, проверьте usage, Cloud – только со spend limit.

Чем Composer дешевле Claude Opus на одной задаче?

По прайсу Cursor Composer 2.5 – $0.50/$2.50 за 1M input/output, Opus 4.8 – $5/$25. Composer в first-party пуле, Opus ест API-пул. Для рутины сначала Composer.

Нужен ли OpenClaw, если уже есть Cursor?

Не делайте OpenClaw "на всякий случай". Сначала артефакт в Cursor Composer с критерием готово. OpenClaw-класс – позже, когда есть стоп-кран и понятный ROI.

Когда Make выгоднее "агента для бизнеса"?

Когда сценарий линейный: форма → таблица → уведомление. Make Free – 1 000 credits/мес, Core от ~$9. Агента берите, когда нужно "подумать и править файлы".

Как понять, что агент зациклился и пора стоп?

После 2–3 циклов нет файла по критерию "готово", текст крутится вокруг одного – стоп. Перепишите ТЗ, уберите лишнее, не жмите "ещё раз" на том же промпте.

Хватит ли "бесплатных AI агентов" для первой задачи?

Для первой бизнес-задачи лучше Cursor Pro + Composer, чем пять бесплатных вкладок без usage и стопа. Hobby – только проба.

Стоит ли сразу брать Ultra или Cloud Agents?

Нет. Сначала локальный прогон и таблица сравнения. Cloud – после spend limit и дешёвой модели; Ultra – когда automation реально ест $200+.
