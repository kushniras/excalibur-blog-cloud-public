Текст поста в Cursor уже готов, а картинки нет. Марина открывает Midjourney, ждёт очередь, получает красивый кадр без читаемого русского заголовка, правит в Canva и снова возвращается в чат. Боль знакома: нужна обложка "вчера", но нейросеть для создания картинок кажется "только для дизайнеров", а MCP – чем-то для программистов. Ответ проще: одна обложка из того же чата Cursor через MCP, без вкладки Midjourney.

Когда не гонять Midjourney вместо MCP

Если нужен один разовой кадр вне проекта – вкладка генератора допустима. Если кириллица на обложке обязательна – не надейтесь на "красивый английский" из чужой очереди. Типичная ошибка: править в Canva час и потерять файл вне Cursor. На практике: зелёный MCP → один бриф → один кадр в папке проекта.

MCP (Model Context Protocol) – это "розетка" инструментов внутри Cursor: агент сам вызывает генерацию картинки, а не копирует файл из соседней вкладки. Для маркетингового кадра с кириллицей берите GPT Image 2; фон при необходимости снимайте отдельным tool. Workflow вечера: зелёный MCP → бриф на 5 строк → один кадр → сохранение в папку проекта. Parent "нейросеть для генерации изображений" – около 61526 показов/мес, primary "нейросеть для создания картинок" – 10846 (Яндекс Вордстат, Россия, 13.07.2026).

Сюрприз из поиска: SERP по нейросетям для картинок забит ТОП-12 и ТОП-35 рейтингами генераторов, а рабочий угол "обложка из Cursor через MCP, не уходя во вкладку" почти пустой. На практике Midjourney часто сильнее в "артистичном" стиле, но слабее на длинных русских фразах – для обложки блога вкладка Discord часто лишняя боль, а не must-have. Ниже – как сгенерировать картинку с помощью нейросети прямо в Cursor за один вечер.

Чем MCP в Cursor отличается от вкладки Шедеврум или Midjourney

Боль "зачем ещё один сервис, если есть онлайн-генератор" снимается простой аналогией. Онлайн-нейросеть – это магазин за углом: вышли, купили картинку, вернулись. MCP – розетка в той же комнате, где вы уже пишете пост. Agent (помощник в чате Cursor) вызывает tool сам: вы подтверждаете клик, файл появляется рядом с текстом. Не делайте прыжок Midjourney → Discord → скачать → Canva → снова Cursor, если задача – читаемый маркетинговый кадр.

Критерий Вкладка онлайн-генератора MCP в Cursor
Где вы работаете Отдельный сайт / Discord Тот же чат, где пишете пост
Кириллица на кадре Часто "красиво, но без текста" GPT Image 2 заточен под production-текст
Сохранение Ручное скачивание Файл или URL в папке проекта
Стиль серии Легко разъехаться Повтор брифа + связь с DESIGN.md / AURA

Вердикт: для маркетолога MCP – не "ещё один API для разработчиков", а способ держать текст и картинку в одном workflow. Используйте вкладку Midjourney, если нужен чисто художественный стиль без длинного RU-заголовка.

Подключите MCP "Всё подключено" до зелёного статуса

Боль "боюсь сломать Cursor / красный статус / это для программистов" лечится коротким чеклистом, а не правкой JSON наугад. Точка входа – MCP "Всё подключено": в ленте Ковчега (пост #1309) к нему добавили Nano Banana 2 через Kie.ai и GPT Image 2 вместо старой версии. Ориентир новичка: в Settings → Tools & MCP статус сервера зелёный, в списке видны tools генерации и удаления фона.

  1. Шаг 1. Откройте Cursor → Settings → Tools & MCP (или готовый remote-сервер из кабинета MCP).
  2. Шаг 2. Подключите MCP по инструкции кабинета; ключи держите в env / кабинете, не в тексте чата.
  3. Шаг 3. Перезапустите Cursor после правки mcp.json – иначе статус "залипнет".
  4. Шаг 4. Проверьте зелёный индикатор и список tools (gpt-image / remove background).
  5. Шаг 5. Если красный – откройте Output → MCP Logs; не правьте JSON наугад.
  6. Шаг 6. При сомнениях вернитесь к гайду подключение MCP в Cursor.

Типичная ошибка – сразу гнать десять промптов, пока статус красный. Сделайте сначала "розетку", потом картинку. Agent по умолчанию спросит подтверждение перед вызовом tool – это нормально, не "поломка".

Соберите бриф картинки: формат, ratio и кириллица

Боль "не знаю, с чего начать – размер, формат, промпт" решается до генерации. Aspect ratio (соотношение сторон) – это форма кадра: 16:9 для обложки блога, 1:1 для квадратного поста, 4:5 для ленты. Добавьте в бриф точную русскую фразу и слово "readable Cyrillic" – иначе модель уйдёт в декор без читаемого заголовка.

  1. Шаг 1. Зафиксируйте цель: обложка блога, картинка к Telegram-посту или hero лендинга – один формат за раз.
  2. Шаг 2. Выберите ratio: 16:9 / 1:1 / 4:5 под площадку.
  3. Шаг 3. Напишите точный текст на кадре кириллицей (короткая фраза, не абзац).
  4. Шаг 4. Опишите стиль в 1–2 предложениях и запреты: чужие логотипы, токсичный текст, мелкая "простыня".
  5. Шаг 5. Попросите ОДИН shot через gpt-image-2; не открывайте Midjourney "на всякий случай".
  6. Шаг 6. Оцените читаемость с телефона; при необходимости image-to-image (правка по уже готовому кадру) – второй промпт.
  7. Шаг 7. Сохраните удачный бриф в заметку – его можно повторить на второй задаче.

Например, бриф Марины: "обложка 16:9, заголовок "Скидка до пятницы", плоский маркетинг-стиль, без логотипов конкурентов". Избегайте промпта "сделай красиво" без ratio и текста – получите открытку без пользы для поста.

Сгенерируйте один кадр, снимите фон и сохраните файл

Боль "генерация висит / timeout / чат замирает" не повод бежать в Шедеврум. В сообществе Cursor длинные sync-вызовы MCP иногда рвутся около 60 секунд (ошибка -32001 на ACP-пути). Не делайте слепой тройной retry: дождитесь URL/job или повторите один раз, откройте MCP Logs. В IDE-пути таймаут обычно мягче, чем на CLI.

В Agent-чате попросите сгенерировать один кадр через gpt-image-2 по вашему брифу и подтвердите вызов tool. Если нужен стикер или слой без фона – уберите фон отдельным MCP-tool (у gpt-image-2 нет transparent background "из коробки"). Тот же паттерн в реальном проекте: AURA Designer и PARALAXIMUS требуют gpt-image-2 + remove background – не "картинку где угодно".

Схема workflow:
Бриф (цель + ratio + текст) → вызов gpt-image-2 в чате → оценка кириллицы → при необходимости remove background → файл в assets/covers/

Сохраните PNG/JPG (или рабочий URL) в папку проекта assets/ или covers/. Секреты и токены – только в env / кабинете MCP; не коммитьте mcp.json с живыми ключами. Создание картинки нейросетью онлайн во вкладке можно оставить запасным планом, но сначала доведите MCP-сценарий до файла в проекте.

Чеклист перед выкладкой и повтор на второй задаче

Боль "боюсь слить ключи и запороть репозиторий картинками" закрывается коротким чеклистом, а не страхом. Проверьте глазами то, что реально увидит читатель с телефона.

  • Ratio совпадает с площадкой (обложка ≠ квадратный сторис).
  • Кириллический заголовок читается без "кракозябр".
  • Стиль не спорит с DESIGN.md, если файл уже есть.
  • Секреты не в git; картинки лежат в assets/, не в корне "как попало".
  • Тот же бриф можно повторить на второй задаче без нового хаоса.
  • Серия кадров дальше – через карусель Instagram нейросетями или AURA, а не десять разных стилей.

Критерий успеха: в Tools & MCP статус зелёный; Agent вызвал tool генерации; в папке проекта лежит готовый PNG/JPG (или рабочий URL); русский заголовок читается; секреты не в git; есть короткий бриф, который вы уже готовы повторить. Если всё совпало – вы умеете генерировать маркетинговую картинку из Cursor без команды дизайнеров.

Что сделать дальше после первой обложки

Первый кадр – точка входа, не финал. Используйте тот же бриф на второй задаче (пост или hero), затем выровняйте серию через DESIGN.md и AURA. Если автоматизация контента интересует шире – разберите вайбкодинг для маркетинга в Cursor и сценарии нейросети для постов с автопостингом. Курс по Make.com и вайбкодингу на kv-ai.ru – отдельный слой, если хотите связать картинки с воронками без кода.

Частые вопросы

Какая нейросеть для создания картинок подойдёт новичку в Cursor?

Сделайте старт на GPT Image 2 через MCP: модель заточена под production-кадры с текстом, в том числе кириллицей. Nano Banana 2 через Kie – запасной характер стиля, если нужен другой "вкус". Не начинайте с десятка вкладок "бесплатно без регистрации" – сначала один зелёный MCP и один удачный кадр.

Чем MCP лучше онлайн-генератора вроде Шедеврума?

Онлайн-сервис удобен для разового эксперимента. MCP держит генерацию в том же чате, где пишете пост: меньше копирования, проще сохранить файл в проект и повторить бриф. Для серии обложек это экономит час прыжков по вкладкам.

Нужен ли Midjourney, если есть Cursor и MCP?

Не обязательно. Midjourney силён в художественном стиле, но для длинного русского заголовка на обложке GPT Image 2 обычно практичнее. Открывайте Midjourney, только если сознательно гонитесь за "артом", а не за читаемостью.

Как убрать фон через MCP?

Сгенерируйте кадр, затем вызовите tool удаления фона (remove background) – отдельно от генерации. У gpt-image-2 прозрачный фон из коробки не поддерживается: не ждите волшебной галочки "transparent" в том же вызове.

Сколько стоит первая генерация?

Точная цена зависит от провайдера и лимитов вашего кабинета MCP / API – не фиксируйте "бесплатно навсегда" из поискового хвоста. Проверьте актуальные лимиты в кабинете сервиса и у провайдера модели перед серией кадров.

Что делать, если генерация зависла или вылез timeout?

Откройте MCP Logs, подождите завершения или URL/job, повторите один раз. Избегайте слепых тройных retry и параллельного запуска Midjourney "на всякий случай" – сначала доведите до конца один вызов в Cursor.
