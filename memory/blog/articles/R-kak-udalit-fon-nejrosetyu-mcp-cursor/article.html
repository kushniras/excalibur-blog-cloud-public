Чтобы удалить фон нейросетью и быстрее получить PNG для поста, в Cursor вызовите инструмент вырезки на готовый кадр – не вкладку remove.bg и не промпт "сделай transparent" – и сохраните файл в проект. Боль знакома: сорвать срок обложки из-за ручной возни в браузере. Результат сегодня: один честный PNG с прозрачностью за один вызов MCP-tool в Cursor.

Когда не усложнять вырезку

Если кадр разовый и вы уже в браузере на remove.bg – можно вырезать там, без MCP. Если нужен именно стиль генерации "сразу без фона", всё равно проверьте альфа-канал: модели часто рисуют белый фон вместо прозрачности. Не тащите AURA и параллакс-агента в задачу "убери фон с одного PNG".

Критерий готово: файл в проекте, прозрачность видна на цветной подложке, путь воспроизводим одним вызовом tool. Пачку кадров запускайте только после одного чистого примера.

Текстовый промпт редко даёт настоящий альфа-канал. Нужен MCP-tool вырезки на готовый кадр и проверка на клетчатом фоне. Локальный Recraft и AURA – не условие первого вечера. Сначала один кадр, потом пачка.

Нужен один файл: стикер, слой для hero или обложка, где фон уже "прилип". Результат – PNG с клетчатым preview (это альфа, настоящая прозрачность), объект на месте, края приемлемы для вставки в пост или лендинг.

Почему "просто напиши прозрачный" не работает

Сайты и совет "попроси модель без фона" для кадра, который уже лежит в Cursor, часто ведут в тупик.

Способ Что получаете Когда уместен
MCP remove-background PNG с прозрачностью в проекте Пост/обложка в Cursor сегодня
Вкладка remove.bg Файл в браузере вручную Разовый кадр вне пайплайна
Промпт "transparent" Часто имитация, не альфа-канал Почти никогда для продакшена
Локальный Recraft MCP Свой стек вырезки Когда готовы к установке npm

Итоговый вердикт: для поста в срок вызывайте готовый tool вырезки на кадр. Не надейтесь, что текстовый промпт "убери фон" даст честный PNG.

Модель генерации картинок и инструмент вырезки – разные вещи. У OpenAI прямо сказано: gpt-image-2 сейчас не поддерживает background: "transparent". Просите "прозрачный фон" – получаете клетку в пикселях, сплошной цвет или отказ. Это не альфа: при вставке остаётся белая "подложка".

Вкладка remove.bg ок как запасной прогон. Для файла в Cursor я бы не начинал с неё: уходите из проекта, ловите preview низкого разрешения, а HD снова упирается в кредиты. Бесплатный контур API remove.bg – порядка 50 вызовов в месяц, типично в preview. Для одного стикера иногда хватает. Когда файл уже здесь, быстрее вызвать вырезку из того же редактора.

Генерация кадра ≠ вырезка с альфой. Сначала нужен готовый PNG/JPG/WEBP, потом отдельный tool remove-background.

Что подготовить до вызова

Возьмите один кадр. Форматы для tool recraft_remove_background в MCP-KV: PNG, JPG или WEBP. Вход – URL картинки. Лимиты схемы на сегодня:

  • файл не больше 5 MB;
  • не больше 16 мегапикселей;
  • сторона не длиннее 4096 px;
  • меньшая сторона не короче 256 px.

Если картинка тяжелее или огромнее – уменьшите до лимита до вызова. Иначе tool упадёт на размере, а не на "качестве нейросети".

Картинку положите так, чтобы агент мог отдать на неё URL (публичная ссылка или то, что ваш MCP принимает как вход). Цель одна: не сгенерировать новый кадр и не собрать три размера обложки – только вырезать фон у уже готового файла.

Зелёный MCP: куда смотреть

MCP в Cursor – это подключённые инструменты, которыми агент может пользоваться после вашего одобрения. Проверка: Settings → Tools & MCP. Нужен зелёный сервер, где есть вырезка фона.

Два рабочих входа:

  1. MCP-KV ("Всё подключено") – путь канала: один сервер с картинками и tool recraft_remove_background. Старт: mcp-kv.ru.
  2. Recraft remote – официальный путь вендора: в ~/.cursor/mcp.json или project .cursor/mcp.json указываете remote URL https://mcp.recraft.ai/mcp, логин через OAuth. Документация: Recraft remote MCP и Cursor MCP.

Локальный npm-пакет @recraft-ai/mcp-recraft-server помечен Deprecated. README репозитория просит уходить на remote. Я бы не ставил deprecated local "на вечер" – только remote или уже зелёный MCP-KV.

После правки конфига перезапустите MCP/агент по подсказке Cursor и снова откройте Settings → Tools & MCP: сервер зелёный, tool вырезки виден. Без этого шага "попросить удалить фон" останется обычным текстом в чате.

Один вызов: remove-background на кадр

В Agent напишите прямо: вызови tool remove-background / recraft_remove_background на этот кадр (укажите файл или URL), сохрани PNG в папку проекта. Не "сделай прозрачный фон промптом" – именно tool вырезки.

Когда Cursor покажет запрос на одобрение инструмента – одобрите. Дождитесь ответа без ошибки размера или лимита. Сохраните результат рядом с исходником, например sticker-cutout.png.

Кредиты: в Recraft Studio Remove background = 1 credit; MCP-tool вырезки списывает subscription credits так же, как в Studio. Отдельный Recraft API balance – другой счётчик: background removal ≈ $0.01 / 10 API credits за запрос. Не путайте studio-кредиты и API balance в кабинете Recraft.

Как понять, что получилось

Откройте PNG в превью. Клетчатый фон вокруг объекта – признак альфы. Объект на месте, без дыр в середине. Края на 100% zoom: логотип, рука, край стикера. Для поста или слоя hero "приемлемо" важнее "идеальные волосы".

Вставьте PNG в макет hero, обложку или стикер. Если появляется белая или цветная подложка – это не альфа, а картинка с нарисованной клеткой. Тогда вернитесь к вызову tool, а не к новому промпту "transparent".

Волосы, мех и стекло часто рвут край. Не обещайте себе идеал за один проход. При браке: другой кадр с более простым контуром или один запасной прогон на remove.bg. Self-host rembg и Python-GPU в тот же вечер я бы не трогал – это уже другой заход, не первый PNG.

Куда вставить сегодня – и что не делать

Готовый cutout сразу идёт в:

  • стикер или карусель в соцсеть;
  • отдельный слой поверх фона hero;
  • обложку поста, где нужен объект без "коробки" фона.

Не смешивайте задачи. Генерация кадра с нуля, три размера обложки, полный параллакс hero и установка дизайн-субагента – соседние темы. Сегодняшний критерий: PNG с альфой лежит в проекте, tool отработал, вставка без подложки.

Если MCP ещё не подключали или хотите отдельно разобрать генерацию и обложку после cutout – это optional, не условие этой статьи: подключение MCP в Cursor, генерация картинок через MCP, обложка для поста, эффект параллакса в hero.

Короткий чеклист

  1. Кадр в лимитах (≤5 MB, ≤16 MP, сторона 256–4096).
  2. Settings → Tools & MCP: зелёный mcp-kv или Recraft remote.
  3. В Agent – явный вызов remove-background / recraft_remove_background.
  4. PNG в папке проекта, клетчатый preview, края ок для стикера/слоя.
  5. Вставка в макет без белой подложки.

Готово = все пять пунктов. Не готово = tool красный, ошибка размера, или "прозрачность" только нарисована пикселями.

Частые вопросы

Можно ли обойтись одной вкладкой remove.bg?

Можно для разового превью. Для файла, который уже в Cursor, я бы шёл через MCP: меньше прыжков и результат сразу в проекте. Вкладка – запасной план при браке краёв.

Почему не попросить gpt-image-2 сразу без фона?

Потому что transparent у этой модели сейчас не поддерживается. Вырезка – отдельный шаг после готового кадра.

Ставить ли локальный Recraft MCP из npm?

Нет для первого вечера. Официальный local пакет Deprecated; канон – remote https://mcp.recraft.ai/mcp или зелёный MCP-KV.

Нужен ли AURA или параллакс-агент сегодня?

Нет. Сегодня достаточно одного tool вырезки. Субагенты – когда cutout уже стабильно получается и вы сознательно расширяете пайплайн.

Разборы MCP, вырезки и сборки контента в Cursor – в канале t.me/maya_pro и в MAX max.ru/maya_pro. Если после первого PNG захотите системно связать нейросети и автоматизацию маркетинга – курс kv-ai.ru/obuchenie-po-make.

Как понять, что PNG действительно без фона?

Откройте файл на клетчатом или цветном фоне в просмотрщике. Если вокруг объекта шахматная прозрачность или виден цвет подложки – альфа на месте. Серый "псевдофон" в превью модели не считается.

Можно ли вырезать сразу пачку кадров?

На первый вечер лучше один кадр и один вызов tool. Пакет имеет смысл, когда путь сохранения и качество уже проверены на одном примере.
