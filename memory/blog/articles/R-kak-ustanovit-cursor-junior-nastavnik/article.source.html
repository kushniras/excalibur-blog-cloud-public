Чтобы начать вайбкодинг обучение сегодня вечером, поставьте в Cursor одного русскоязычного наставника — Cursor Junior с GitHub Horosheff/cursor-jr, перезагрузите окно редактора и вызовите его через Task(cursor-jr) или команду /cursor-jr на свой сценарий: пост, лендинг или простую автоматизацию. Критерий вечера: в разделе Customize (страница плагинов, навыков и субагентов) виден cursor-jr, а в ответе наставника есть минимум три понятных следующих шага.

Рейтинги курсов на месяцы эту задачу не закрывают. Нужна не «школа вайбкодинга», а кнопка в редакторе и разбор вашей ситуации. Junior — неофициальный плагин с лицензией MIT, не аффилирован с Cursor Inc.; это отдельный помощник-наставник, а не общий чат и не офис из десятков агентов.

Зачем наставник, а не топ курсов

Открыли Cursor после ролика про вайбкодинг — и упёрлись в Ask, Agent, Rules, MCP, плагины. Страх нормальный: кажется, что один неверный клик сломает проект. Курсы в выдаче обещают недели. Я бы не уходил в рейтинг школ, пока внутри редактора нет живого ориентира на русском.

Cursor Junior объясняет интерфейс простыми словами, ведёт к первой задаче и не гонит сразу в сравнение сторонних нейросетей. На старте «ии для вайбкодинга» — встроенный агент Cursor плюс этот наставник. Сравнивать модели до первой своей задачи я бы не стал: время уйдёт на выбор, а не на результат.

Плагин — это папка, которую Cursor подхватывает после Reload (перезагрузки окна). Субагент-наставник — помощник, которого вызывают по имени. Rules — короткие правила для агента. MCP — подключённые инструменты. Эти слова сами по себе не требуют курса; их достаточно понимать в момент действия.

Что подготовить до установки

Нужен установленный Cursor, аккаунт и одна рабочая папка или проект. В чат не кидайте токены, пароли и ключи API. Git удобен, но не обязателен: репозиторий можно скачать ZIP с GitHub и распаковать.

В тот же вечер не ставьте «заодно» рои вроде AURA, Офис, Excalibur или TEYA. Один наставник — один фокус. Офис агентов — следующий уровень после того, как Junior уже ответил на ваш сценарий, а не обязательный шаг до него.

Перед крупными правками агента в Cursor есть checkpoints: откат без Git. Это страховка, если боитесь «сломать проект» на первых шагах.

Установка Cursor Junior

Официально локальный плагин лежит в ~/.cursor/plugins/local/имя-плагина с файлом .cursor-plugin/plugin.json в корне этой папки. Затем Restart Cursor или команда Developer: Reload Window. С июня 2026 (Cursor 3.9) plugins, skills, MCP и субагенты собраны на одной странице Customize — там и ищите cursor-jr после установки.

Windows: быстрый путь из README

  1. Откройте терминал и клонируйте репозиторий: git clone https://github.com/Horosheff/cursor-jr.git
  2. Перейдите в папку: cd cursor-jr
  3. Запустите скрипт: .\scripts\install-plugin.ps1
  4. Полностью перезапустите Cursor

Скрипт кладёт плагин туда, откуда Cursor его читает. Если Git нет — скачайте ZIP с GitHub, распакуйте и скопируйте содержимое в локальную папку плагинов вручную (см. ниже).

Любая ОС: ручное копирование

  1. Скопируйте проект в ~/.cursor/plugins/local/cursor-jr (на Windows путь обычно %USERPROFILE%\.cursor\plugins\local\cursor-jr)
  2. Проверьте: в корне именно этой папки есть .cursor-plugin/plugin.json, а не ещё одна вложенная cursor-jr/cursor-jr
  3. В Cursor откройте Command Palette → Developer: Reload Window

Частая ошибка community — вложенный путь вроде local/my-plugin/my-plugin: плагин молча не грузится. Manifest должен быть в корне папки плагина. На корпоративном Enterprise-аккаунте иногда нужен разрешённый Allow Local Plugin Imports — без него локальные плагины не появятся.

Проверка: установка жива

Откройте Customize. Там должны быть видны плагины и субагенты; ищите cursor-jr. Если списка нет или плагин серый — снова Reload Window, проверьте путь без вложенной папки и настройки third-party / local plugins.

Вызовите наставника одним из способов из README:

  • Task(cursor-jr)
  • команда /cursor-jr в чате

Опционально на Windows можно прогнать verify-install.ps1 из репозитория — это проверка «установка жива», не обязательный ритуал. Команды maintainer, синхронизацию базы знаний и /cursor-jr-sync в первый вечер не трогайте: для первого сеанса они не нужны.

Получилось, если одновременно: Customize показывает cursor-jr и вызов дал ответ. Не получилось — почти всегда путь, Reload или политика Enterprise, а не «вы недостаточно программист».

Первый сеанс: свой сценарий и ≥3 шага

Не просите «расскажи всё про Cursor». Опишите одну задачу своими словами, например:

«Я маркетолог без кода. Хочу сделать черновик поста / простой лендинг / маленькую автоматизацию. Объясни, куда жать в Cursor под эту задачу, и дай минимум три следующих шага на ближайшие дни. Без лишнего жаргона.»

Хороший ответ наставника: что открыть сейчас (Ask или Agent), чего пока не трогать, и список из трёх и больше шагов — например Ask → разбор diff → Plan, или дальше Rules / Skills / MCP по мере нужды. README Junior ведёт новичка по такой лестнице на несколько дней; вам сегодня достаточно первого этажа.

Сохраните ответ: скопируйте в заметку или файл в проекте. Это ваш маршрут на завтра, а не повод ставить ещё пять плагинов сегодня.

Чем это отличается от обычного чата: общий чат отвечает на вопрос и забывает контекст обучения; Junior заточен на онбординг — MCP, Rules, Skills, Canvas — и ведёт к действию в интерфейсе. Чем отличается от роя «офис»: один readonly-наставник, а не десять ролей сразу. Я бы держал эту границу жёстко в первый вечер.

Частые вопросы

Чем это отличается от YouTube-курса по вайбкодингу?

Курс даёт общую программу на недели. Junior стоит внутри вашего Cursor и разбирает ваш пост, лендинг или автоматизацию здесь и сейчас. Вайбкодинг обучение бесплатно на старте — через MIT-репозиторий, без оплаты школы.

Какой ИИ выбрать новичку?

На первый вечер — встроенный агент Cursor и наставник Junior. «Лучшие ии для вайбкодинга» в рейтингах можно смотреть позже; до первой своей задачи сравнение моделей обычно только тормозит.

Чем Junior не является?

Это не полный тур по всем кнопкам редактора и не установка роя агентов. И не замена соседним гайдам про Rules или MCP: те темы имеют смысл после того, как наставник уже дал вам три шага.

Что делать, если команды нет?

Вернитесь к пути плагина и Reload. Пока cursor-jr не виден в Customize, вызывать нечего. Вложенная папка и запрет local imports на Enterprise — две самые частые причины «тишины».
