Открываете поиск "нейросеть для создания видео" – топ-15 сайтов и "бесплатно без VPN". Пробуете один: длинный промпт, восемь минут ожидания, ролик 16:9 без оффера, кредиты минус. Хотите клип под Reels/Shorts ради охвата и досмотра, но боитесь, что без студии и кода не выйдет; соседние гайды про монтаж эфира, а у вас только текст акции. Ниже путь через Make (это сценарий из кубиков без кода) к одному MP4 9:16 (вертикаль под ленту).

Когда не собирать видео-цепочку сегодня

Если нет сценария и одной мысли ролика – генерация MP4 только сожжёт время. Если нужен живой эфир без монтажа – не тащите Make и очередь. Типичная ошибка: гнаться за топ-15 нейросетей вместо одного готового 9:16. На практике один сценарий → один файл → ручная проверка звука и субтитров.

Сравните зоопарк вкладок и один workflow (порядок шагов) – это цепочка "текст оффера → модуль генерации → файл". Make + HeyGen (сервис ролика с говорящим аватаром) дают клип 15–30 секунд за вечер после зелёного Run once (один тестовый прогон сценария). Результат: сможете выложить файл под охват без съёмки с нуля. Полный автопилот без правки – ещё не норма; сначала один готовый MP4.

Люди чаще ищут "создание видео", чем точный запрос "по тексту". На практике выигрывает не бренд модели, а один прогон с понятным статусом и скачанным файлом. Если уже есть длинный эфир – это другой слой; если нужна только раскадровка под съёмку – тоже другой. Здесь в первый вечер: текст акции → вертикальный ролик под охват, без CapCut в стартовый день.

Сравните три двери: генерация, монтаж, сценарий

Типичная ошибка – смешать три задачи в одну вкладку и слить время на чужой слой.

Задача Что на входе Что на выходе Куда идти
Генерация по тексту Оффер 15–30 сек MP4 9:16 Этот гайд: Make + HeyGen
Монтаж эфира Длинное видео Нарезка Shorts нейросеть для монтажа Reels
Сценарий рилс Тема и зритель Таблица кадров сценарий рилс нейросетью

Не начинайте первый вечер с Whisper и CapCut, если эфира нет. Не уходите в раскадровку на 12 кадров, если нужен уже готовый файл. Выберите одну дверь: сегодня – генерация по тексту. Соседний монтаж long→Shorts на GitHub – это Hyperion, не стартовая точка этого гайда.

Чеклист брифа на 20 секунд до Make

Без брифа модуль нарисует "красиво", но без оффера – досмотр падает в первые секунды. Сделайте лист из семи пунктов и только потом открывайте сценарий.

  1. Шаг 1. Один оффер в одной фразе (что купить / куда написать).
  2. Шаг 2. Хук на первые 3 секунды: боль зрителя или цифра.
  3. Шаг 3. Длина 15–30 секунд, не "минута обо всём".
  4. Шаг 4. Формат вертикали 9:16, не горизонталь 16:9.
  5. Шаг 5. Голос: нормальная громкость; избегайте шёпота и музыки поверх речи.
  6. Шаг 6. Сохраните исходный текст оффера в заметке – пригодится для подписи.
  7. Шаг 7. Уберите NSFW и "оживить чужое фото" – это вне темы первого вечера.

Ориентир готовности брифа: прочитали текст вслух за ~20 секунд, оффер слышен без догадок. Например, "Скидка 20% на консультацию до пятницы – напишите в Direct" лучше, чем "мы любим клиентов". Если фраза звучит как слоган агентства – перепишите до конкретного действия зрителя.

Прогресс: чеклист брифа закрыт; текст готов к модулю.

Соберите сценарий Make + HeyGen по шагам

Цель секции – убрать страх "куда жать". Используйте официальный модуль HeyGen в каталоге Make, не чужие топы сервисов и не зеркала главной страницы платформы.

  1. Откройте Make → новый scenario (это пустой холст сценария).
  2. Добавьте соединение HeyGen: API-ключ (это пароль из кабинета сервиса) берёте в HeyGen → Settings → Subscriptions & API.
  3. Источник текста: вручную в поле модуля или строка из Google Sheets.
  4. Модуль Create / Generate Avatar Video: вставьте бриф, выберите аватар и голос.
  5. Добавьте Retrieve / ожидание по video_id – генерация асинхронная: pending → processing → completed или failed.
  6. Сохраните video_url или скачайте файл на диск / в Drive.

В реальном проекте цепь короче зоопарка вкладок: один вход текста, один create, один retrieve. Не делайте сразу десять аватаров "на пробу" – кредиты уйдут в брак до первого completed. Официальный путь настройки ключа и модулей описан у HeyGen в разделе интеграции с Make.

Прогресс: scenario собран, соединение живое, текст оффера в модуле.

Запустите Run once и скачайте вертикальный MP4

Кнопка тестового прогона уже знакома из блока выше. Нажмите её и дождитесь зелёного статуса в History (журнал запусков сценария).

  1. Запустите Run once один раз.
  2. Дождитесь status completed (означает "готово"); при failed читайте текст ошибки, не жмите подряд.
  3. Скачайте MP4 по video_url – ссылка временная, не откладывайте на неделю.
  4. Проверьте вертикаль 9:16 на телефоне в полноэкранном превью.
  5. Проверьте, что оффер слышен или читается в кадре либо в подписи.
  6. Проверьте громкость: звук не "шепчет", речь не тонет в музыке.

Результат первого прогона: файл на диске, оффер на месте, можно отдать в выкладку. Если всё зелёное – вы уже сэкономили рутину съёмки с нуля на этот клип и получили материал под досмотр, а не горизонтальный брак.

Прогресс: Run once зелёный, MP4 9:16 скачан, оффер и звук ок.

Как починить кредиты, зависание и render failed

Часто ломается не "нейросеть", а входные данные и баланс.

  • insufficient_credit – в сообщении обычно видно, сколько кредитов есть и сколько нужно; пополните или укоротите ролик.
  • script too short – текст для озвучки короче ~1 секунды TTS; добавьте фразу с оффером.
  • processing долго – подождите poll Retrieve; не плодите параллельные create.
  • Make + Google Drive audio_url без публичного доступа – в сообществе HeyGen такие кейсы дают Video render failed; кредиты иногда возвращают, но время нет.

Чеклист ретрая перед вторым прогоном:

  1. Сделайте один create после исправления, не три подряд.
  2. Уберите чужие Drive-ссылки без доступа; используйте upload asset или публичный URL.
  3. Исправьте слишком короткий скрипт – ориентир: оффер + одна фраза хука.
  4. Проверьте баланс до второго прогона.
  5. Добавьте паузу или явный Retrieve by ID, если create сразу "теряется" без статуса.

Прогресс: ошибки читаемы; ретрай без паники и без ощущения, что "сломали аккаунт".

Частые вопросы

Подойдёт ли генерация ролика по тексту маркетологу без кода?

Да. Путь первого вечера – визуальный сценарий Make и модуль HeyGen: бриф, API-ключ, Run once, скачать MP4. Код и Cursor не обязательны для первого файла.

Чем генерация по тексту отличается от монтажа эфира?

Генерация берёт текст оффера и отдаёт новый MP4. Монтаж режет уже снятое длинное видео. Если эфир есть – откройте гайд по монтажу Reels; если только текст акции – оставайтесь здесь.

Сколько ждать рендер и когда повторять Run once?

Дождитесь status completed или failed. Не спамьте create при processing. При failed проверьте кредиты, длину скрипта и доступ к audio_url, затем один ретрай.

Можно ли стартовать с бесплатного лимита и не слить кредиты?

Можно один короткий ролик 15–30 сек с готовым брифом. Не гоняйте десять аватаров "на вкус". Free tier и кредиты конечны – сначала качество оффера, потом объём.

Нужен ли MCP-video, чтобы нейросеть сделала клип?

Нет для первого вечера. Mcp-video в этом репозитории – про посты WordPress. Генерацию клипа в Make даёт модуль HeyGen; MCP подключайте позже под автопост, если понадобится.

Куда отдать файл после проверки звука и оффера?

В ручную выкладку Reels/Shorts или в соседний сценарий автопоста Shorts из Google Sheets. Раскадровку под живую съёмку подключайте только если решите снимать сами, а не генерировать.
