Маркетолог скачал Cursor «как все советуют», час кликал Marketplace с Atlassian и Datadog, поставил три расширения «на всякий случай» – агент начал путаться, а человек решил, что плагины не для него. Боль знакома: экран полный MCP, Rules и субагентов, а страшно «поставить не то» и снова упереться в пустой чат. Ответ за вечер – один готовый плагин (лучше Cursor Junior), а не оркестр с нуля: установите пакет, увидите агента и сохраните первый делегированный результат.

Плагин Cursor – это не «ещё одно расширение как в VS Code», а готовый пакет помощников: rules (правила поведения), skills (инструкции «как делать задачу»), agents (готовые роли), команды и при необходимости MCP (короткая «розетка» к внешним сервисам). Официальный блог Cursor прямо пишет: связка MCP + skills внутри плагина сильнее «голого» MCP. Workflow новичка: выбрать один GitHub-пакет → поставить через Customize или локальный install → один прогон → чеклист на завтра. Разберите, чем плагин отличается от чата и от «просто субагента»

Боль «кажется, это только для программистов» лечится простой картинкой. Чат Cursor – это диалог: вы пишете, модель отвечает. Субагент – отдельная роль с задачей (например, «напиши бриф»). Плагин – коробка, куда уже сложили несколько ролей, правил и навыков, чтобы не собирать офис вручную.

На практике новичок путает три вещи: расширение VS Code (кнопки в редакторе), плагин Cursor (пакет агентов) и mouse-cursor из игр в поиске. Ориентир: если в README речь про skills, agents и Customize – это наш кейс. Не делайте день-1 из сборки своих субагентов: сначала используйте готовый пакет.

Вердикт: для маркетолога плагин = «офис в коробке». Хотите понять базу редактора – откройте как пользоваться Cursor AI. Хотите углубить вайбкодинг после Junior – вайбкодинг для маркетинга в Cursor.

Выберите один плагин под задачу вечера

Боль «Marketplace полон Datadog – что ставить?» закрывается таблицей выбора, а не коллекцией «на всякий случай». Типичная ошибка day-1 из reader_story: три плагина сразу → агенты спорят → человек бросает Cursor.

Задача вечера Плагин Когда брать Day-1?
Понять Cursor и первый бриф Cursor Junior Новичок, русский наставник, Task/slash Да
Контент и страницы Офис веб-страниц Нужен офис из ~12 субагентов После Junior
Сетка 20–200 страниц TEYA E2E-сетка сайтов, 19+ ролей Нет
Авто-блог SEO/GEO Excalibur ~10 субагентов под контент-завод Нет

Итоговый вердикт: в день-1 поставьте только Cursor Junior. Офис, TEYA и Excalibur – следующий уровень, когда один агент уже дал черновик. Избегайте enterprise-карточек Atlassian/Datadog, если ваша цель – маркетинг без DevOps.

Surprising fact из docs и форума: плагин с skills внутри сильнее голого MCP, но команда /add-plugin с произвольным GitHub URL иногда залипает на старом коммите. Поэтому ниже – путь README или локальная папка, а не «магическая строка».

Установите Cursor Junior за вечер без DevOps

Боль «установка с GitHub не сработала / агент не виден» почти всегда про один из трёх путей. Customize (с Cursor 3.9, changelog 22.06.2026) – единая страница плагинов, skills и MCP в сайдбаре. Marketplace – витрина проверенных пакетов. Локальный путь ~/.cursor/plugins/local – то, что подтверждают инженеры Cursor, когда import «залип».

  1. Шаг 1. Откройте README Horosheff/cursor-jr и скопируйте ссылку репозитория – код писать не нужно.
  2. Шаг 2. Сделайте clone по инструкции README (или скачайте ZIP) в удобную папку на компьютере.
  3. Шаг 3. Запустите скрипт установки из README (install-plugin.ps1 на Windows) – он кладёт плагин туда, где Cursor его ждёт.
  4. Шаг 4. Альтернатива: положите папку плагина в ~/.cursor/plugins/local и сделайте Reload Window – так рекомендуют docs и issue plugin-template #4.
  5. Шаг 5. Проверьте Customize: плагин или агент должен появиться в списке после перезапуска.
  6. Шаг 6. Уберите другие «тестовые» плагины из активного набора на этот вечер – один пакет, один фокус.
  7. Шаг 7. Не делайте ставку только на /add-plugin с сырым GitHub URL: community-тред фиксирует stale pin; при сбое вернитесь к шагу 4.

В реальном проекте люди час ждут «волшебную установку», не перезагрузив окно. Добавьте привычку: после install – Reload, затем Customize. Если нужен MCP позже – сначала прочитайте подключение MCP в Cursor, не тащите пять серверов в день-1.

Запустите первый прогон и сохраните результат

Боль «поставил – и снова пустой чат» закрывается одним делегированием с критерием «готово». Используйте Task(cursor-jr) или команду /cursor-jr, если README так указывает. Попросите простое: «объясни Ask vs Agent простыми словами» или «собери бриф Telegram-поста на 5 строк».

  1. Шаг 1. Откройте чат/агента Junior и сформулируйте одну задачу на русском – без пяти целей сразу.
  2. Шаг 2. Дождитесь ответа и сохраните текст в файл проекта (например, drafts/brief-post.md).
  3. Шаг 3. Проверьте, что в Customize плагин всё ещё активен – иначе завтра «пропадёт».
  4. Шаг 4. Сделайте короткий комментарий себе: что сработало, что спросить завтра.
  5. Шаг 5. Если ответ пустой – перезапустите Cursor и повторите один запрос, не ставьте второй плагин.
  6. Шаг 6. Когда Junior стабилен, можно смотреть офис субагентов: AI-агенты и субагенты для маркетинга.

Например, за вечер достаточно одного брифа поста – это уже делегированный результат, а не «поигрался с чатом». Результат, который вы сможете повторить: файл на диске + понятный путь установки. Если Junior просит уточнить задачу – ответьте одним предложением, не открывайте второй чат «на всякий случай»: так вы быстрее поймёте, где кончается путаница и начинается рабочий workflow.

Соберите чеклист безопасности и план на завтра

Боль «боюсь сломать CRM / таблицы» решается правилами, а не смелостью. Секреты (токены, пароли) держите в .env, как в постах про Офис: не в чате и не в скринах. MCP подключайте только если плагину реально нужен внешний сервис. Один активный плагин в день-1 – ваш страховочный трос: откат = отключить пакет в Customize. Честно говоря, новички чаще ломают нервы, чем проект: они ставят пять MCP «потому что красиво в Marketplace» и теряют нить запроса.

Чеклист перед тем как закрыть ноутбук:

  • В Customize виден Junior (или выбранный пакет).
  • Есть один сохранённый черновик результата.
  • Секреты не в промпте; боевые таблицы не трогали.
  • Завтрашний повтор описан в 3 строках.

Критерий успеха до FAQ: плагин виден → один прогон выполнен → черновик сохранён → чеклист повтора готов. Сделаете это – вы уже не «зритель Marketplace», а человек с рабочим агентом. Дальше по желанию: Cloud Agents в Cursor Cloud Agents или связка с автоматизацией в Make + MCP.

Если хотите системно пройти вайбкодинг и агентов с куратором – разбор курса на kv-ai.ru/obuchenie-po-make; свежие релизы плагинов – в канале @maya_pro. Инструмент дня всё равно ставьте с GitHub, а не «вместо курса».

Частые вопросы

Какие плагины для Cursor поставить первыми?

Сделайте старт с Cursor Junior. Если цель вечера – контент и страницы, следующим берите Офис веб-страниц. TEYA и Excalibur оставьте на потом: там десятки субагентов и другой масштаб задач.

Чем плагин отличается от субагента?

Субагент – одна роль. Плагин – пакет: часто несколько субагентов плюс skills, rules и иногда MCP. Используйте плагин, когда не хотите собирать офис вручную.

Нужен ли MCP сразу после установки?

Нет. Не делайте day-1 из коллекции серверов. MCP (розетка к внешним сервисам) подключайте только если README или задача явно требуют доступ наружу.

Можно ли поставить Cursor Junior без опыта GitHub?

Да. Проверьте README: копируете ссылку или ZIP, запускаете install-скрипт или кладёте папку в local plugins. Код писать не нужно – нужен аккуратный копипаст шагов.

Сколько плагинов достаточно новичку?

Один в день-1. Ориентир: сначала стабильный прогон Junior, потом второй пакет под новую задачу. Избегайте «три на всякий случай» – агенты начинают мешать друг другу.

Почему /add-plugin с GitHub иногда «не обновляется»?

Community-форум Cursor фиксирует stale pin на старом коммите. Уберите ставку на одну команду: сделайте local clone в ~/.cursor/plugins/local и Reload Window по docs.
