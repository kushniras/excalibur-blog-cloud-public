Открываете Wordstat в браузере, копируете десяток фраз в таблицу – и через час непонятно: что писать на страницу услуги, а что оставить «на потом». Key Collector кажется обязательным, нейросеть без цифр рисует красивые, но пустые ключи. Страница снова мимо поиска, трафика и заявок. Ниже короткий маршрут: спрос → мини-кластер 5–15 фраз → один бриф под один URL.

Подбор ключевых слов под одну страницу – это не тысяча строк в парсере. Сначала зелёный Wordstat MCP (инструмент спроса в чате Cursor), один parent ниши, чистка мусора из «похожих», затем 5–15 фраз с показами за ~30 дней и бриф (H1 + блоки + FAQ). Результат: сможете писать текст под реальный спрос и заявки, а не гадать ключи из головы.

Представьте витрину магазина: цифры спроса видны, а «корзину» под страницу – бриф – никто сам не соберёт. Parent «вордстат» даёт порядка 106 тыс. показов в месяц, а точный how-to «подбор ключевых слов» – около 690: люди ищут инструмент шире, чем готовый гайд. При этом «похожие» в Wordstat часто засорены оффтопом вроде «к чему падают ключи». Без ручной чистки мини-кластер превращается в мусор – типичная ошибка, которая съедает вечер.

Карта на сегодня: подключить MCP → выбрать одну страницу и parent → снять топ → оставить 5–15 одного интента → собрать бриф → проверьте готовность. Полное ядро и таблица в Make – потом, не сейчас.

Сравните мини-подбор, Key Collector и полное ядро

Одна боль – разные масштабы. Если взять не тот инструмент, снова утонете в тысяче строк без брифа.

Подход Что обычно получаете Что делать сегодня
Key Collector / тысяча строк Неделя настройки, нет брифа под услугу Не делайте так для одной страницы
Ключи «из головы» нейросети Красивые фразы без показов Избегайте цифр без Wordstat
Копипаст из браузерного Wordstat час Куча фраз, непонятно H1 Сделайте мини-кластер 5–15 + бриф

Задача Что нужно Инструмент дня
Одна услуга / одна статья 5–15 фраз + один бриф Wordstat MCP в Cursor

На практике Key Collector нужен, когда объём уходит за сотни фраз. Для одной страницы он избыточен. Не делайте «ядро на весь сайт» в первый вечер: сначала закройте один URL. Рейтинги «ТОП сервисов подбора» полезны для обзора рынка, но не дают готовый бриф под ваш оффер.

Прогресс: видите контраст «парсер / одна страница / полное ядро».

Подключите Wordstat MCP и дождитесь зелёного инструмента

Wordstat (статистика поисковых запросов Яндекса) показывает, сколько раз фразу искали. Тот же спрос через MCP вызываете прямо в чате Cursor – без копипаста из браузера. Без зелёного инструмента дальше нет смысла гадать цифры.

  1. Шаг 1. Откройте гайд Wordstat MCP setup (~20 минут) или каталог MCP-KV.
  2. Шаг 2. Создайте API Key – это ключ доступа к облаку Яндекса – и Folder ID в AI Studio; добавьте роль search-api.webSearch.user.
  3. Шаг 3. Включите биллинг: без него часто приходит 403, и инструмент остаётся «красным».
  4. Шаг 4. В Cursor проверьте, что виден wordstat_get_top_requests (или аналог community MCP).
  5. Шаг 5. Сделайте один тестовый top-запрос по широкой фразе ниши – нужен успешный ответ с цифрами.
  6. Шаг 6. Если MCP ещё не подключали вообще – сначала подключение MCP в Cursor.

Официальный метод topRequests отдаёт данные за последние ~30 дней; один запрос тратит одну единицу квоты; при лимите приходят 429 или 503. Используйте тестовый вызов экономно. Избегайте выдуманных частотностей «из головы нейросети» – Ядрышко в методологии прямо запрещает цифры без MCP.

Прогресс: один зелёный top-запрос в чате Cursor.

Выберите одну страницу и одну parent-фразу

Интент (зачем человек ищет) должен быть один на страницу. Parent (широкая фраза ниши) – это вход в топ: «ремонт стиральных машин», «курс make для маркетолога», не «весь сайт целиком».

Сделайте выбор до снятия топа:

  • Один URL или оффер (услуга / статья / лендинг).
  • Один доминирующий интент: купить, узнать, сравнить – не всё сразу.
  • Одна parent-фраза + при желании 1–2 уточняющих seed.

Например, страница «настройка Wordstat MCP» не должна тянуть ключи про «купить ключи от квартиры». Добавьте в заметку строку: URL + интент + parent. Уберите из плана «собрать всё по нише». Workflow (порядок шагов) – это сначала рамка страницы, потом цифры, потом текст.

Прогресс: URL, интент и parent записаны.

Как снять топ Wordstat и почистить «похожие»

Associations (похожие запросы рядом с топом) часто выглядят «золотом», но на практике там много оффтопа. Без чистки получите мусорный кластер и бриф мимо трафика.

  1. Шаг 1. Запустите wordstat_get_top_requests по выбранному parent.
  2. Шаг 2. Запишите фразы и показы в заметку или таблицу – только живые цифры из ответа.
  3. Шаг 3. При необходимости повторите для 1–2 seed, не для десятка родителей.
  4. Шаг 4. Уберите оффтоп из «похожих», бренды конкурентов и чужие города.
  5. Шаг 5. Оставьте 5–15 фраз одного интента; лишнее вычеркните в минус-слова.
  6. Шаг 6. Проверьте глазами в wordstat.yandex.ru, если сомневаетесь в спорной фразе.
  7. Шаг 7. Не делайте второй круг «ещё чуть-чуть» до бесконечности: аппетит вечера – мини-кластер.

Типичная ошибка – тащить в кластер всё, что «похоже звучит». Методология Ядрышко: один кластер = один интент + один основной URL. Соберите список так, чтобы каждая строка имела показы, а не «кажется полезным». На практике после чистки список короче топа Wordstat – это нормально: лучше 8 точных фраз, чем 40 строк мусора.

Прогресс: в заметке 5–15 фраз с цифрами, минус-слова отмечены.

Соберите один бриф под страницу: H1, блоки, FAQ

Цифры без ТЗ снова оставят вас с таблицей и пустой страницей. Бриф (короткое ТЗ на текст) закрывает боль «что писать».

  1. Шаг 1. Выберите главный ключ для H1 – ближайший к интенту страницы.
  2. Шаг 2. Набросайте title и description черновиком под тот же спрос.
  3. Шаг 3. Добавьте 3–5 блоков (H2) из хвоста фраз: вопросы, сравнения, этапы.
  4. Шаг 4. Сделайте 2–4 FAQ-заготовки из длинных хвостов спроса.
  5. Шаг 5. Впишите один CTA и одну следующую страницу сайта, если нужна воронка.
  6. Шаг 6. Проверьте: бриф отвечает только этому URL, без чужих интентов.

В реальном проекте после брифа текст пишут руками или отдают в Cursor: дальше написать статью нейросетью или SEO-страница без кода. Избегайте смешения: сегодня подбор и бриф, не черновик на 3000 знаков. Если бриф уже есть, а ключи снова «из головы» – вернитесь к топу Wordstat и проверьте цифры ещё раз.

Прогресс: один бриф H1 + блоки + FAQ готов.

Чеклист готовности и куда идти дальше

Вернёмся к старту: вместо хаоса копипаста из браузера у вас проверяемый артефакт. Чеклист перед текстом:

  • Зелёный wordstat_get_top_requests (или эквивалент).
  • 5–15 фраз одного интента с показами Wordstat (~30 дней).
  • Минус-слова и оффтоп вычеркнуты.
  • Один URL и один бриф (H1, 3–5 блоков, FAQ).

Если всё отмечено – результат вечера закрыт: сможете писать под спрос, а не гадать. Проверьте ещё раз, что в списке нет выдуманных цифр.

Частые вопросы

Подойдёт ли подбор ключевых слов в Cursor маркетологу без SEO-стека?

Да, если цель – одна страница, а не ядро на весь сайт. Нужны аккаунт Yandex Cloud, зелёный MCP и готовность вручную вычеркнуть оффтоп. Парсер Key Collector в первый вечер не обязателен.

Чем бесплатный Wordstat в браузере отличается от MCP?

UI удобен для сверки глазами. MCP даёт те же показы в чате Cursor и быстрее собирает список под бриф. Для вечернего мини-кластера удобнее зелёный инструмент, а не час копипаста.

Как не спутать подбор под SEO-страницу и под Яндекс Директ?

Для страницы сайта держите один интент и бриф текста. Для Директа чаще нужны объявления и минус-слова кампании. Не смешивайте оба ТЗ в одном мини-кластере – получите расползание фраз.

Что делать, если инструмент Wordstat красный или отвечает 403?

Проверьте API Key, Folder ID, роль search-api.webSearch.user и биллинг по гайду MCP-KV. Без оплаты облака 403 – частый стоп. Пока нет зелёного top-запроса, не собирайте «ключи из головы».

Сколько фраз достаточно для одной услуги?

Ориентир – 5–15 одного интента с живыми показами. Меньше пяти – тонкий бриф; больше пятнадцати на старте – риск снова уйти в «ядро». Сначала закройте один URL.

Когда переходить к полному семантическому ядру?

Когда одна страница уже закрыта брифом и текстом, а нужно разложить весь сайт по URL. Тогда откройте гайд по полному ядру и Ядрышко – не раньше первого результата мини-кластера.
