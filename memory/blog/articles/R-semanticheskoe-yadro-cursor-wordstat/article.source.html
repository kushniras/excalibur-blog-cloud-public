Маша написала 12 «ключей из головы» для лендинга услуг. Через месяц из поиска – ноль. Друг сказал «собери семантическое ядро», она открыла Key Collector, увидела цену и Windows-парсер и закрыла вкладку. Боль знакомая: кажется, ядро только для SEO-профи, а выдуманные фразы не работают. Ответ проще: подключите Wordstat через MCP в Cursor, снимите реальные частотности и за вечер получите кластеры, URL-карту и 3 брифа – без агентства.

Семантическое ядро в 2026 – это не Excel на десять тысяч строк, а карта «о чём люди спрашивают» плюс страница под каждый смысл. Wordstat уже живёт в Yandex Cloud Search API (API Key + Folder ID), а не только в старом OAuth. Parent-запрос «семантическое ядро» даёт около 4559 показов/мес по России. Workflow новичка: MCP-KV → проверка цифры → Ядрышко или ручной промпт → clusters + url-map + 3 брифа.

Честно говоря, споры «мертво ли ядро из-за нейросетей» звучат громко, но авторы гайдов всё равно рисуют карту интентов. Нейросети пишут текст; ядро говорит, о чём писать. MCP (Model Context Protocol) – «розетка» для Cursor: редактор дергает внешний сервис, как приложение – погоду. Здесь розетка ведёт в Wordstat. Ориентир за вечер: живая цифра показов, кластеры и три ТЗ. Если MCP ещё не трогали – гайд как подключить MCP в Cursor.

Чем ядро отличается от списка ключей из головы

Список «из головы» – это фантазия. Ядро – снимок спроса: что реально ищут в Яндексе, с какой частотностью и с каким намерением. На практике частотность – это сколько раз в месяц люди вбивали фразу (оценка Wordstat). Кластер – группа близких фраз с одним смыслом: «что такое X» и «X цена» – разные кластеры, им нужны разные страницы.

Например, parent «семантическое ядро» тянет хвост: «семантическое ядро сайта» (788), «как собрать семантическое ядро» (365), «кластеризация семантического ядра» (93). Это не «магия SEO», а план контента. Типичная ошибка – смешать информационный и коммерческий интент в одну кучу и ждать, что одна страница закроет всё.

Правило на пальцах: один кластер = один интент + один URL. Не делайте «простыню» из 200 ключей без страниц. Используйте ядро как карту Topic Authority, а не как плотность вхождений в текст.

Если цель – чтобы нейропоиск цитировал сайт, ядро стыкуется с GEO-оптимизацией: сначала темы и структура, потом answer-блоки и FAQ.

Подключите Wordstat MCP и проверьте цифру одним запросом

Страх «я сломаю всё» снимается маленьким первым шагом. Сделайте аккаунт в экосистеме Яндекса, затем по гайду Wordstat MCP setup на mcp-kv.ru получите API Key в AI Studio, Folder ID и роль search-api.webSearch.user. Биллинг в Cloud нужен: без него часто прилетает 403.

  1. Шаг 1. Откройте дашборд MCP-KV «Всё подключено» и вставьте API Key + Folder ID.
  2. Шаг 2. Нажмите «Проверить и сохранить» – дождитесь зелёного статуса, не пропускайте.
  3. Шаг 3. В Cursor зайдите в Settings → Tools & MCP (или mcp.json) и подключите сервер MCP-KV.
  4. Шаг 4. В чате Agent попросите top requests по parent вашей ниши (учебный пример – «семантическое ядро»).
  5. Шаг 5. Проверьте, что пришла цифра показов, а не пустой ответ или ошибка 401/403.
  6. Шаг 6. Сохраните скрин или строку в заметку проекта: это ваш baseline спроса.

Часто ломается на мелочах: неверный Folder ID, нет роли, квота 429. Избегайте «подключил наугад и сразу гоню тысячу фраз» – сначала один parent. Официальная справка Wordstat: yandex.ru/support2/wordstat. Документация Cursor по MCP: cursor.com/docs/mcp.

Как собрать ядро через Ядрышко или ручной промпт

Когда цифра живая, можно собирать пакет. Субагент Ядрышко (пост #1315) ставится одной командой install.sh / install.ps1, после Reload Window запускается как /core с URL сайта и регионом. На выходе: clusters.csv, url-map, content-briefs, HTML/XLSX-отчёт.

В реальном проекте без Ядрышка тоже можно: попросите Cursor seed → top requests → минус-слова → кластеры по интенту → CSV. Но методология та же: semantic-core-methodology.md прямо запрещает выдумывать частотности. Без MCP-KV Core обязан пометить цифры как неподтверждённые – это нормально, не «баг».

  1. Шаг 1. Установите Ядрышко из GitHub или подготовьте папку semantic/ вручную.
  2. Шаг 2. Задайте нишу, регион (Россия / 225) и URL сайта.
  3. Шаг 3. Снимите хвост Wordstat по parent и 2–3 seed-фразам.
  4. Шаг 4. Уберите мусор: чужие бренды, оффтоп, «ядерные» ассоциации не про SEO.
  5. Шаг 5. Сгруппируйте фразы по интенту (информация / коммерция / транзакция).
  6. Шаг 6. Добавьте колонку URL: создать, обновить или склеить.
  7. Шаг 7. Выпишите 3 P0-темы на ближайшую неделю.

Схема workflow:
Ниша → Wordstat MCP (цифра) → чистка мусора → кластеры → URL-карта → 3 брифа → TODO на 7 дней

Не делайте ставку только на ИИ-кластеризацию «как на математику SERP»: модель группирует смыслы, финальный взгляд глазами – ваш. Wordstat ≠ весь поиск, лимиты API есть; MCP-KV снижает порог через дашборд.

Соберите URL-карту: один смысл – одна страница

Боль «не понимаю кластер vs куча ключей» лечится таблицей. Откройте 05-clusters.csv и 06-url-map.csv (или свой лист). У каждого кластера должна быть судьба: create / refresh / merge. Сделайте пометку «создать» только там, где страницы ещё нет; «обновить» – где текст слабый.

Что сравниваем Список из головы Ядро через Wordstat + Cursor
Откуда фразы Догадки Топ Wordstat по нише
Частотности Нет или выдуманы Цифры API / MCP
Структура Плоский список Кластер = интент + URL
Пакет за вечер 12 строк в заметках CSV + url-map + 3 брифа
Риск Пишете мимо спроса Нужна ручная чистка мусора

Итоговый вердикт: для старта сайта и блога берите связку Cursor + Wordstat MCP + Ядрышко. Key Collector оставляйте, если уже живёте в Windows-парсере и платных базах. Новичку быстрее зелёный MCP и один parent, чем неделя установки KC.

Используйте статусы из методологии Core (ok / refresh / create / merge) как язык команды: так проще отдать задачу копирайтеру или себе-на-выходные. Добавьте в url-map приоритет P0–P3, иначе всё станет «срочным».

Чеклист: три брифа и критерий «готово»

Боль «не знаю, что писать после сбора» закрывается файлом 07-content-briefs.md или ручным промптом на три P0-кластера. В брифе нужны H1, блоки смысла, FAQ и целевой URL – этого хватит, чтобы сесть писать сегодня.

Проверьте себя по success-критерию до того, как звать агентство:

  • В папке проекта есть clusters.csv (или лист кластеров) с реальными частотностями.
  • Есть url-map с пометками создать/обновить.
  • Есть минимум 3 контент-брифа.
  • У parent-запроса ниши сохранена цифра из Wordstat MCP, не «на глаз».
  • Мусор вычеркнут, интенты не смешаны в одном URL.

Этот чеклист – ваш стоп-кран: если пункта нет, не масштабируйте на 50 статей. Ориентир на первую неделю – три текста по P0, не «весь рынок». Дальше ядро кормит контент-завод и помогает не плодить дубли.

Углубить Cursor и Make можно в курсе Make.com + вайбкодинг. Ядрышко и MCP-KV docs при этом остаются открытыми инструментами, не «закрытым курсом вместо софта».

Что сделать сегодня вечером

  1. Подключите Wordstat в MCP-KV и добейтесь зелёного статуса.
  2. Снимите parent своей ниши – сохраните цифру показов.
  3. Поставьте Ядрышко или соберите CSV вручную через промпт.
  4. Почистите мусор и разметьте create/refresh в url-map.
  5. Выберите 3 P0-брифа и напишите черновик первого.
  6. Завтра: сверьте интенты глазами и только потом масштабируйте.

Не обещаем «заменить SEO-агентство навсегда» – только быстрый старт с живыми данными и пакетом файлов. Ручная проверка смыслов остаётся вашей.

Частые вопросы

Как собрать семантическое ядро новичку без Key Collector?

Сделайте связку Cursor + Wordstat MCP (MCP-KV) + чистка мусора + кластеры по интенту. Проверьте один parent-запрос, затем соберите CSV и три брифа. Ядрышко ускоряет пакет файлов, но логика та же вручную.

Нужен ли Key Collector, если есть Wordstat MCP?

Для первого ядра сайта – нет. KC полезен тяжёлым SEO-командам с парсерами и большими базами. Новичку быстрее зелёный статус MCP и живая цифра, чем неделя установки Windows-софта.

Сколько запросов достаточно на старт?

Ориентир: один сильный parent, хвост топа Wordstat и 15–40 очищенных фраз в 5–10 кластерах. Не гонитесь за тысячами строк в первый вечер – важнее url-map и три брифа.

Чем кластер отличается от списка ключей?

Список – плоская куча. Кластер – фразы с одним намерением под один URL. «Что такое X» и «купить X» не живут на одной странице. Используйте правило «один кластер = один интент».

Как из ядра сделать контент-план?

Откройте url-map, возьмите P0 со статусом create/refresh, выпишите 3 брифа (H1, блоки, FAQ). Добавьте даты на 7 дней. Так ядро превращается в план, а не в архив Excel.

Что делать, если MCP отвечает 401 или 403?

Проверьте API Key, Folder ID, роль search-api.webSearch.user и биллинг Cloud. Избегайте повторных массовых вызовов при 429 – сначала почините доступ по гайду Wordstat MCP setup.
