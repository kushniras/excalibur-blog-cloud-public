Лена попросила ChatGPT: «сделай скрипт, который из Excel соберёт UTM-ссылки». Получила код, не поняла, куда его вставить, скопировала криво – ничего не заработало. Друг сказал «ставь Cursor», она увидела Agent и Rules и закрыла окно: страх сломать ноутбук. Боль знакома: вайбкодинг звучит как «для программистов». Ответ другой – одна микрозадача за вечер, правило «не трогай исходники» и рабочий файл в папке.

Вайбкодинг простыми словами: вы описываете задачу обычным языком, а ИИ-агент в Cursor пишет и правит файлы проекта, пока вы смотрите результат. Это не курс Python и не замена Make или Tilda. Ориентир на вечер: один мини-инструмент (UTM, отчёт, мини-HTML), проверка глазами и сохранённый промпт. Parent «вайбкодинг» – около 19606 показов/мес по России. Workflow: копия данных → правило → Plan → Agent по шагам → diff → шаблон.

Андрей Карпатый в феврале 2025 описал vibe coding как «Accept All, не читать diffs» для weekend-проектов. Для маркетингового инструмента безопаснее наоборот: читать diff, держать checkpoint и не просить «собери весь SaaS за один промпт». Cursor – это редактор с агентом: агент (Agent) – помощник, который сам создаёт и меняет файлы по вашей инструкции. Checkpoint – точка отката, если что-то пошло не так. Ниже – как собрать первый результат без команды разработчиков.

Поймите вайбкодинг на пальцах: задача агенту, не учебник Python

Вайбкодинг – это когда вы говорите «мне нужен калькулятор UTM к пятнице», а не изучаете синтаксис. ИИ для вайбкодинга (нейросеть внутри Cursor) пишет код и HTML, вы принимаете или отклоняете правки. На практике это ближе к постановке ТЗ ассистенту, чем к «программированию с нуля».

Чем отличается от привычного:

Критерий Чат ChatGPT No-code (Make / Tilda) Вайбкодинг в Cursor
Где живёт результат Текст в чате, некуда вставить Сценарий или страница в сервисе Реальные файлы в вашей папке
Что вы делаете Копируете код наугад Собираете блоки мышкой Описываете боль → смотрите diff
Откат Почти нет История сценария Checkpoint / копия папки
Когда брать Черновик текста Интеграции, лендинг-конструктор Парсер, UTM, мини-отчёт, кусок HTML

Вердикт: не делайте ставку «либо Make, либо Cursor». Используйте Make для связок сервисов, Tilda для конструктора, Cursor – когда нужен маленький свой инструмент под ваши данные. Типичная ошибка – таскать архивы кода из чата и удивляться, что «не запускается».

Если позже понадобится целый лендинг без кода – отдельный гайд лендинг в Cursor AI без кода. Сейчас цель уже: один файл, одно действие.

Выберите одну маркетинговую боль на вечер – не весь SaaS

Страх «не знаю, с чего начать» лечится коротким списком. Сделайте выбор ровно одной боли из четырёх – остальное на завтра.

  • Генератор UTM-ссылок из таблицы кампаний
  • Отчёт: CSV → понятная HTML-таблица с итогами
  • Мини-HTML блок оффера (не весь сайт)
  • Список URL: почистить, разметить, выгрузить

Например, «парсер конкурентов + автопостинг + дашборд» – это три проекта, не один вечер. Избегайте промпта «собери продукт как у Notion». Проверьте критерий заранее: файл открывается и делает одно действие на 2–3 ваших строках данных.

  1. Шаг 1. Выпишите боль одной фразой: «мне нужно X из файла Y».
  2. Шаг 2. Создайте пустую папку проекта на компьютере.
  3. Шаг 3. Положите туда копию Excel/CSV, не оригинал.
  4. Шаг 4. Откройте эту папку в Cursor (Open Folder).
  5. Шаг 5. Запишите критерий успеха в заметку: «открывается и считает UTM для 3 строк».
  6. Шаг 6. Уберите из головы список из 20 «ещё фич» до первого результата.

Соберите в Cursor: правило проекта, Plan, diff без паники

Боль «агент сломает Excel» снимается правилом до первой правки. Добавьте в проект короткое правило (Rules – постоянная памятка для агента): «не удаляй исходники, работай только в новых файлах, отвечай по-русски, один шаг за раз». В docs Cursor правила лежат в .cursor/rules как .mdc либо в AGENTS.md – суть та же: агент читает их каждый раз.

  1. Шаг 1. Напишите правило «только новый файл» и сохраните его в проекте.
  2. Шаг 2. Попросите Plan из 3–5 шагов без правок файлов; согласитесь с планом.
  3. Шаг 3. Запустите Agent только на шаг 1 плана.
  4. Шаг 4. Просмотрите diff (что изменилось) и примите точечно, не Accept All.
  5. Шаг 5. Проверьте результат глазами на 2–3 примерах из вашей таблицы.
  6. Шаг 6. Если сломалось – Restore Checkpoint или вернитесь к копии папки.
  7. Шаг 7. Доведите до открытия файла: HTML в браузере или скрипт с понятным выводом.

Схема workflow:
Боль одной фразой → копия данных → правило «не трогай исходники» → Plan → Agent по одному шагу → чтение diff → проверка 3 строк → готовый артефакт

В реальном проекте вторая правка без отката часто «убивает» всё, что сделала первая – об этом пишут и на Хабре неразработчики. Не делайте слепой Accept All на большой пачке файлов. Официально Cursor создаёт checkpoints перед крупными правками: это ваша кнопка «назад» без знания Git.

Сохраните шаблон: rule, skill или готовый промпт на завтра

Боль «завтра снова с нуля» закрывается шаблоном. Сделайте из удачного диалога короткий промпт: задача, входной файл, запреты, критерий «готово». Skills в Cursor – это папка с SKILL.md: по сути сохранённый сценарий, который вызываете через «/» или отдаёте агенту. Используйте skill, когда задачу повторяете каждую неделю; для разового UTM хватит текстового промпта в заметках.

Если интерфейс пугает жаргоном, поставьте наставника Cursor Junior (cursor-jr) – русскоязычный онбординг Ask/Plan/Agent, 7-дневный маршрут и разбор «агент всё сломал». Якорь канала: пост #1331. Когда захотите связать вайбкодинг с Make и системным обучением – курс Make + нейросети + вайбкодинг на kv-ai.ru; сначала добейте один файл сегодня.

Для внешних данных через MCP (розетка сервисов в Cursor) пригодится гайд подключение MCP в Cursor – но не в первый вечер, если цель только UTM из локальной таблицы.

Чеклист: инструмент готов, исходники целы, следующий шаг понятен

До FAQ зафиксируйте success criteria. Пройдите чеклист вслух – если хоть один пункт «нет», вечером ещё не «готово».

  • В папке есть новый файл-результат (не только текст в чате)
  • Файл открывается и делает одно действие на ваших данных
  • Исходный Excel/CSV на месте, агент его не затёр
  • В чате виден понятный diff принятых правок
  • Есть checkpoint или копия папки на случай отката
  • Сохранён промпт или rule «как повторить завтра»
  • Список «ещё 20 фич» отложен; следующий шаг один и ясный

Ориентир успеха: к пятнице у Лены (и у вас) есть рабочий HTML или скрипт плюс шаблон, а не недоделанный «продукт». Проверьте ещё раз: не делайте вид, что «почти работает» – либо три строки сходятся, либо правьте точечно.

Что дальше: повторите тот же workflow на второй боли из списка; при желании подключите CursorJr; углубите связку агентов и автоматизации в материале Make AI-агенты и MCP. Если нужна система с нуля до продакшена – вернитесь к обучению по Make и вайбкодингу после первого рабочего файла.

Частые вопросы

Вайбкодинг – что это такое простыми словами?

Вы описываете задачу обычным языком, агент в редакторе создаёт файлы, вы проверяете результат. Сделайте первую микрозадачу (UTM или отчёт), а не «изучить программирование». Это и есть вайбкодинг на пальцах.

Чем Cursor лучше чата ChatGPT для маркетинга?

В чате код висит текстом без места запуска. В Cursor Agent пишет сразу в папку проекта, показывает diff и даёт checkpoint. Используйте чат для идей, Cursor – когда нужен рабочий файл.

С какой задачи начать новичку?

Одна боль: UTM из таблицы, CSV→HTML-отчёт, мини-блок оффера или чистка списка URL. Не делайте «весь SaaS». Ориентир – один артефакт за вечер.

Нужно ли знать код, чтобы заниматься вайбкодингом?

Нет курса Python. Нужно читать, что изменилось, и проверять 2–3 примера руками. Избегайте слепого Accept All – это и есть главная ошибка новичков.

Чем вайбкодинг отличается от no-code Make?

Make связывает сервисы блоками без файлов кода. Вайбкодинг в Cursor собирает свой мини-инструмент в файлах. На практике часто гибрид: Tilda/Make + Cursor под парсеры и отчёты.

Как не сломать исходный Excel?

Добавьте правило «только новый файл», работайте с копией, смотрите diff, держите Restore Checkpoint. Проверьте чеклист выше, прежде чем считать задачу закрытой.

Где учиться вайбкодингу дальше?

Поставьте Cursor Junior как наставника на следующие вечера. Для системного трека Make + нейросети + вайбкодинг смотрите программу на kv-ai.ru после первого рабочего файла.
