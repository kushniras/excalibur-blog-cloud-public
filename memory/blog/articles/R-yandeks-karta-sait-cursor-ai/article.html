Когда карту на сайт не вставлять

Если адреса нет или услуга онлайн – карта не нужна. Если лендинг ещё без контактов – сначала телефон и форма. Типичная ошибка: тяжёлый виджет без lazy и без текста адреса. На практике одна карта, адрес текстом и проверка на мобиле.

Яндекс.Карта на сайт для новичка – это не API и не React, а Конструктор → код iframe → вставка через Cursor Agent. Базовый виджет с меткой работает без API-ключа; ключ нужен только для поиска, маршрутов и панорам на самой карте. Включите "Растянуть по ширине", поставьте loading=lazy и проверьте с телефона, что метка не обрезается.

Поймите задачу: кликабельная метка без кабинета API

Боль звучит так: кажется, что "Яндекс.Карта на сайт" = ключ, npm и страх сломать вёрстку. На практике для контактов нужна кликабельная метка с телефоном в балуне, а не JS API v3. Балун – это всплывающая карточка по клику на метку: название, адрес, телефон.

Сюрприз для многих: справка Конструктора и клуб API Карт подтверждают – базовый виджет работает без ключа. Ключ нужен, только если на карте нужны поиск, маршруты или панорамы. Cursor часто путает это с quickstart JS API v3, где apikey обязателен – отсюда ложный страх "без кабинета нельзя".

Вариант Что получите Нужен ли ключ Кому подходит
Картинка (img) Статичный снимок, без клика Нет Черновик
iframe / script Конструктора Интерактивная карта с меткой Нет для базовой метки Новичок, контакты
JS API v3 Полный контроль кодом Да, в quickstart Разработчик

Итоговый вердикт: для контактов берите Конструктор и iframe. Картинку не ставьте вместо виджета – клиент не откроет балун. JS API v3 и React-обёртки оставьте разработчикам.

Сделайте так: Конструктор → iframe. Не делайте: "добавь карту через npm" и пустой YOUR_API_KEY. Избегайте React-обёрток "на всякий случай".

Соберите виджет в Конструкторе: метка и балун с телефоном

Откройте yandex.ru/map-constructor, войдите в Яндекс и создайте карту. Найдите адрес, поставьте метку. В балуне напишите название и телефон – так клиент сразу видит, куда звонить.

  1. Шаг 1: создайте карту и найдите нужный адрес на схеме.
  2. Поставьте одну метку на точку, куда реально приезжают клиенты.
  3. Заполните балун: название, короткий адрес, телефон.
  4. Нажмите "Получить код карты", включите "Растянуть по ширине" (это width 100%).
  5. Задайте высоту около 400 px и скопируйте код вкладки iframe.
  6. Проверьте превью в Конструкторе: метка на месте, балун открывается.

Типичная ошибка – оставить фиксированные 600×400 и не включить растягивание: на телефоне карта обрезается. Если iframe ругается на масштаб, приблизьте карту или возьмите script без apikey – для базовой метки этого достаточно. По справке iframe только слой "Схема" и крупные масштабы; правки делайте в Конструкторе и копируйте код заново.

Зафиксируйте правило map-embed.mdc, чтобы Cursor не тянул React

Страх сломать сайт появляется, когда Agent на "добавь карту" тащит JS API v3, React или npm-пакет вроде react-yandex-maps-constructor. Например, Cursor Rules работают только как .mdc в .cursor/rules/; обычный .md агент может игнорировать. Для project rules нужен alwaysApply: true.

Откройте папку сайта рядом с index.html и создайте .cursor/rules/map-embed.mdc:

alwaysApply: true
description: Yandex map embed static HTML only

Карта только готовым iframe или script из Конструктора. Один static HTML, Tailwind CDN. Запрещены npm, React, package.json, JS API v3 и обязательный apikey. width="100%", высота ~400 px, loading="lazy". Вставлять под адресом на contacts/services. Не трогать head, меню и формы.

Рекомендация: держите правило жёстким. Используйте alwaysApply: true. Не просите "как в React-примере с GitHub" – иначе вместо одного блока получите стек, который новичок не починит. Уберите из промпта любые намёки на npm и apikey.

Вставь этот iframe Яндекс.Карты под блоком адреса на странице контактов (или услуг). width 100%, height около 400, добавь loading="lazy". Не трогай head, меню и формы. Без API-ключа, npm и React.

Вставьте скопированный код в чат Agent и дождитесь правки HTML. На практике часто ломается высота в процентах: если height="100%", а у родителя высота не задана, карта не отобразится – так в docs Конструктора. Берите ~350–400 px по высоте и 100% по ширине.

Частые вопросы

Нужен ли API-ключ для Яндекс.Карты на сайт?

Для базовой метки из Конструктора – нет. Скопируйте iframe или script без apikey и вставьте на страницу. Ключ добавляйте только если нужны поиск, маршруты или панорамы.

Чем iframe отличается от JS API?

iframe – готовое окошко из Конструктора без программирования. JS API v3 – код для разработчиков с ключом в quickstart. Сегодня берите вкладку iframe и не открывайте docs JS API.

Как вставить Яндекс.Карту на сайт в HTML через Cursor?

Скопируйте код из Конструктора, создайте map-embed.mdc и попросите Agent вставить iframe под адресом с width 100% и loading=lazy. Не принимайте package.json и React.

Можно ли поставить карту без отдельной страницы "Контакты"?

Да. Разместите виджет на лендинге или услугах рядом с адресом и tel:. Отдельная страница контактов удобна, но не обязательна для первого результата.

Почему карта-картинка хуже виджета?

Картинка не открывает балун и не даёт интерактив. Замените img на iframe из Конструктора, заполните балун телефоном и проверьте клик с телефона.

Что делать, если Cursor снова предлагает apikey и React?

Остановите генерацию, усильте map-embed.mdc с alwaysApply: true и повторите промпт: "только готовый iframe Конструктора, без npm и API-ключа". Не оставляйте YOUR_API_KEY в коде.
